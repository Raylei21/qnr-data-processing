# qnr-data-processing

通用问卷数据处理工具。输入一份**问卷 Excel** + 一份**回答数据 Excel**，自动输出带频数/频率表、填空题原话、开放题归纳分析的格式化 Excel 报告。

## 功能

- **自动解析问卷** — 自动识别单选题、多选题、矩阵题、开放题、填空题及对应选项
- **数据清洗** — 按用户自定义规则（AND/OR 组合条件）剔除无效样本
- **分组标签** — 用户通过条件表达式定义任意分组（如"核心用户：Q1=1，Q2=1～3"）
- **T2B/B2B** — 为评分题添加 Top2/Bottom2 Box 汇总行（使用选项索引，通用性强）
- **多选题处理** — 正确以"至少选了一项"为分母计算百分比
- **选项模糊匹配** — 问卷选项与数据标签不一致时自动模糊匹配
- **开放题分析** — 支持自定义关键词分类和自动高频词统计两种模式
- **3-Sheet 输出** — 频数频率表 + 填空题原话 + 开放题归纳，0.5cm 统一行高
- **配置持久化** — 问卷处理配置可保存为 JSON，下次直接复用

## 安装

```bash
# 直接安装
pip install git+https://github.com/Raylei21/qnr-data-processing.git

# 或克隆后本地安装
git clone https://github.com/Raylei21/qnr-data-processing.git
cd qnr-data-processing
pip install -e .
```

依赖：`pandas`、`openpyxl`、`numpy`（使用 pip 安装时自动处理）。

## 快速开始

```bash
cd 你的项目目录
python -m qnr_data_processing
```

按提示依次输入：

1. 问卷文件路径（问卷.xlsx）
2. 数据文件路径（数据.xlsx，需含数字版 + 文字版两个 sheet）
3. 输出文件路径（默认：分析输出表.xlsx）
4. 末尾派生列数（去掉数据末尾非原始回答的计算列）
5. 清洗规则（可选，回车跳过）
6. 分组标签规则
7. 评分题 T2B/B2B 配置（可选）
8. 开放题分析配置（可选）
9. 是否保存配置（下次可复用）

## 输入文件格式

### 问卷文件（问卷.xlsx）

B 列包含题型标记，后续行为选项：

|   | A | B | C |
|---|---|---|---|
| 1 |   | 【单选题】请问您的性别？ |   |
| 2 |   | 男 |   |
| 3 |   | 女 |   |
| 4 |   | 【多选题】您使用过哪些App？ |   |
| 5 |   | 微信 |   |
| 6 |   | 支付宝 |   |

支持的题型标记：`【单选题】`、`【多选题】`、`【开放题】`、`【填空题】`、`【评分题】`

### 数据文件（数据.xlsx）

通常包含两个 sheet：

- **数字版**：每个回答用数字编码（1, 2, 3...）
- **文字版**：每个回答用文字标签

列名格式：`Q1[1].text...(单选)`、`Q2[1].text...(多选)`、`Q34A...`、`HQ33...`

## 分组标签规则语法

```
标签名：条件1，且条件2；或条件3，条件4
```

| 语法 | 含义 | 示例 |
|------|------|------|
| `Q1=2` | 等于某个值 | `Q18=1` |
| `Q1=1～3` | 范围（1,2,3） | `Q19=1～2` |
| `Q1=1，Q2=2` | AND 关系 | `Q18=1，Q19=1～2` |
| `条件1；或条件2` | OR 关系 | `Q18=1；或Q18=2` |
| `Q1≠2` | 不等于 | `Q22≠1` |
| `Q1>3` | 大于 | `Q2>3` |

完整示例：

```
核心篮球迷：Q18=1，且Q19=1～2；或Q18=2，Q19=1
普通篮球迷：Q18=1，Q19=3；或Q18=2，Q19=2；或Q18=3，Q19=1
```

## T2B/B2B 配置

工具自动推荐可能的评分题（选项数匹配的题目），用户确认后可自定义选项索引：

```
Q3 的选项列表:
  1. 非常好
  2. 比较好
  3. 说不上好或差
  4. 比较差
  5. 非常差
  自定义 T2B 索引（用逗号分隔，留空用默认）: 1,2    ← 好评合并
  自定义 B2B 索引（用逗号分隔，留空用默认）: 4,5    ← 差评合并
```

**注意**：默认 T2B=最后 2 个选项、B2B=前 2 个选项。如果评分题是 1=最好→N=最差的排列方式，需要手动调整。

## 开放题分析

两种模式：

**模式 A — 自动高频词统计**：不输入关键词分类，系统自动分词统计频率最高的词汇和字符片段。

**模式 B — 自定义关键词分类**：手动定义分类和关键词：

```
分类规则: 体育/赛事：体育、篮球、足球、NBA
分类规则: 有趣/娱乐：有趣、好玩、搞笑、幽默
分类规则: 专业/深度：专业、权威、深度、精准
```

## 输出文件

生成 3 个 Sheet 的 Excel：

| Sheet | 内容 | 说明 |
|-------|------|------|
| 数据分析表 | 频数+频率表 | 每行一个选项，各分组并排对比，T2B/B2B 着色标记 |
| 填空题原话 | 原始回答列表 | 每道开放题最多显示前 200 条 |
| 开放题归纳 | 关键词分析 | 自动高频词或自定义分类结果 |

## 配置复用

运行结束后保存配置：

```
是否保存当前配置以便下次复用？（y/n，默认 n）: y
  配置名称: 虎扑调研
```

下次运行时直接加载：

```
检测到已保存的配置: 虎扑调研
是否加载已有配置？: 虎扑调研
```

配置文件保存在 `~/.qnr_data_processing/`。
